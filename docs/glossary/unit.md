# Unit

**Definition.** The lowerings of one definition whose published structure reads alike, compiled
against by every referrer under one name: the definition's, with the digest of what the unit
publishes where the definition has more than one unit in the design.

**Contrast.** Not a [class](class.md): a unit publishes a class for its root scope and one for each
generate block, and is the thing named across the compilation boundary. Not a [body](body.md): one
unit may compile to several bodies. Not a [lowering](lowering.md): several lowerings may be one
unit. Not a specialization (LRM 8.25): two applications of a definition with different arguments are
one unit wherever what they publish reads alike.

**Usage notes.** `compilation_unit_model.md` owns what a unit contains and what it publishes;
`specialization_model.md` owns which lowerings are one unit and how it is named.
