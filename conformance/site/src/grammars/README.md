# Grammars

`systemverilog.tmLanguage.json` is the TextMate grammar of Better SystemVerilog Syntax
(https://github.com/hankhsu1996/vscode-better-systemverilog-syntax), copied as it stood at
451db4b2968ed8ac80ad83b6d869b7734897f479 under its MIT licence (`LICENSE` beside it). The case pages
colour SystemVerilog sources with it through Shiki, so the site reads a source as that editor
extension does. To take a newer grammar, copy the file again from that repository.
